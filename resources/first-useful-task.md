# Get one useful task working with AI

Start with one short email you need to send. Choose a task where you know the facts and can judge the result. You can use the AI subscription you already have.

## 1. Tell AI what the email must do

Replace the brackets, attach any shareable notes, and paste this:

```text
I need to write an email to [recipient] about [situation].
The outcome I need is [a decision, an answer, or a next action].
Facts you can use: [your facts].
The recipient needs to know: [important context].
Tone: [how you normally write].
Maximum length: [your limit].

Before drafting, ask me for any missing fact that would change the message.
Do not invent names, figures, dates, or promises.
Write in [Vietnamese / English].
```

## 2. Check the draft

Read it as the person receiving it. Can they tell what you need from them? Check names, numbers, dates, and promises against your notes.

If one part is wrong, say which part and what must change. You can ask: “Keep the facts and structure. Rewrite only the opening so the request is clear in the first sentence.”

## 3. Make sure it is worth using

Compare the usable result with how you would have done the task. Include the effort of explaining, checking, and correcting. If the draft still needs a rewrite, use a good past example and the [quality-checklist guide](quality-checklist.html).

## 4. Keep what worked

Save the successful instructions with the example. For the next similar email, change the facts and recipient. If you keep re-explaining the same background, try the [one-page context template](save-your-context.html).

This starter adapts the one-task work brief and basic email exercise in Tim Tran’s resource library. It is a practice template, not a promise of a particular result.
