# Stop re-explaining the same context

Use this when the task repeats but each new chat needs your role, background, style, and rules all over again. Save one small brief before adding more tools.

## 1. Fill in this one-page brief

```text
ABOUT THIS TASK
- My role: [role and team]
- Task: [the recurring job]
- Reader: [who uses the output and what they need]
- Result needed: [what the output must let them do]

MY STANDARD
- Good example: [attach or name a shareable example]
- Must include: [specific requirements]
- Style: [how I normally write]
- Never: [mistakes or claims to avoid]
- If a fact is missing: ask or mark [CHECK]; do not invent it.

FOR THIS RUN
- New input: [this week’s data or notes]
- What changed: [new constraints or decisions]
- What I need to check before using it: [important facts and choices]
```

## 2. Keep it with the work

If your AI tool supports a saved workspace such as a Project, Gem, or custom GPT, keep the standing brief and good example there. If not, keep them in a note you can reuse. Give it only files and access you are allowed to share.

Keep the “For this run” section separate. The standing instructions should not silently keep last week’s facts as if they were current.

## 3. Try a new chat

Give it the new input for the same task. Check whether it can follow the saved brief without another explanation. If it misses something important, correct the brief as well as the output.

## 4. If you already do this

You do not need to start over. Check what still needs your intervention: finding files, carrying information between tools, or reviewing the result. The [six-step workflow](better-ai-workflow.html) helps you work through one of those handoffs.

Adapted from Tim Tran’s “about me + rules” template and the saved-context method in the AI resource library. The template is a starting point for your own task.
